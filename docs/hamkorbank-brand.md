# Оформление Hamkorbank

Основание: [официальный брендбук Hamkorbank](https://hamkorbank.uz/about-bank/brand-book/) и материалы [сайта банка](https://hamkorbank.uz/), проверенные 12 ноября 2026 года.

## Палитра

| Назначение | Цвет | Источник |
| --- | --- | --- |
| Фирменный акцент, активные элементы, графики | `#18A755` Pigment green | Брендбук |
| Заголовки, основные кнопки, панель входа | `#174A43` Brunswick green | Брендбук |
| Ссылки и наведение на кнопки | `#206158` | Дополнительная палитра брендбука |
| Информационные состояния | `#287A6F` | Дополнительная палитра брендбука |
| Светлая зелёная поверхность | `#F2FFF8` | Дополнительная палитра брендбука |
| Светлая бирюзовая поверхность | `#F0FFFD` | Дополнительная палитра брендбука |
| Светлый акцент на тёмном фоне | `#ABFFCF` | Дополнительная палитра брендбука |
| Основной / вторичный текст | `#202020` / `#666666` | Нейтральная палитра сайта / брендбука |

Фон рабочего пространства, линии, оттенки состояний и подложки — интерфейсные производные. Красный и охра обозначают ошибки и риски; названия статусов сохраняются, чтобы смысл не зависел от цвета.

Белые надписи небольшого размера на `#18A755` не дают контраст 4.5:1. Поэтому основная кнопка использует белый текст на фирменном `#174A43`, а яркий зелёный остаётся акцентом. Логотип скачан без изменений: его знак в исходном SVG имеет цвет `#17A755`; он сохранён как в оригинале.

## Шрифты и логотип

- **Montserrat 400 / 600** — заголовки и крупные числа. Скачаны с действующего сайта банка: латиница, расширенная латиница, кириллица и расширенная кириллица.
- **Golos Text 400 / 500** — текст, формы, навигация и таблицы. Полные WOFF2 с официального сайта содержат латиницу, кириллицу и узбекские символы.
- Все шрифты размещены локально в `frontend/public/brand/fonts/`; загрузка из Google Fonts в приложении не используется.
- Начертания и диапазоны символов описаны в `frontend/src/theme/fonts.css`; `font-display: swap` оставляет текст видимым при загрузке.
- Основной логотип: [исходный SVG банка](https://hamkorbank.uz/assets/images/static/logo.svg), файл `hamkorbank-logo.svg`. Пропорции и цвета сохранены.
- `hamkorbank-mark.svg` содержит исходный контур знака из этого же SVG. Из него отрисованы favicon и PNG-иконки PWA с охранным полем.
- Точные URL, размеры и SHA-256 скачанных файлов: `frontend/public/brand/sources.json`.
- Лицензии шрифтов SIL Open Font License: `Golos-Text-OFL.txt` и `Montserrat-OFL.txt`. Материалы логотипа применяются по правилам брендбука банка.

Один из старых файлов Montserrat Regular на сайте не содержал кириллицу; в интерфейсе используются файлы действующей главной страницы с явными диапазонами символов.

## Организация оформления

- `frontend/src/theme/brand.ts` — палитра и тема Ant Design: кнопки, поля, меню, таблицы, вкладки, модальные окна и статусы.
- `frontend/src/index.css` — оболочка приложения, типографика, страницы входа и адаптивные состояния.
- `BrandLogo`, `AuthShell`, `PageHeading`, `PagePanel` — общие компоненты бренда и структуры страниц.
- Реестр, карта, модели, сертификаты, отчёты, импорт, справочники, пользователи и аудит используют общую тему.
- PWA использует фирменные название, цвета, иконки и локальное кэширование шрифтов. API по-прежнему исключён из кэша.

## Проверка

```bash
cd frontend
npm run lint
npm run build
```

Визуальная проверка выполняется в Chromium на вымышленных данных с перехватом API только внутри тестового браузера. Для обычной работы приложения нужен действующий backend. Проверяются основные разделы, поиск, фильтры, меню, формы и ширины 375, 768, 1024, 1440 px. Тестовые ответы API не входят в приложение.

Результат проверки 12.11.2026: ESLint, TypeScript и production-сборка пройдены; все 19 браузерных проверок пройдены. Проверены также карточка банкомата, обязательная смена пароля и режим уменьшенной анимации. Vite сообщает о размере основного JS-чанка более 1500 kB; сборка завершается успешно.
